# IEEE App

A modern web application built with React 19, Vite, and TailwindCSS.

## Features

- ⚡ **Fast Development** - Powered by Vite with HMR (Hot Module Replacement)
- 🎨 **Modern Styling** - Built with TailwindCSS v4
- 🧭 **Routing** - React Router DOM for navigation
- 🎯 **UI Components** - Lucide React icons
- 📜 **Smooth Scrolling** - Lenis for buttery smooth scroll animations
- ✅ **Testing** - Vitest for unit testing
- 🔍 **Code Quality** - ESLint with React Hooks plugin

## Tech Stack

- **React** 19.2.4
- **Vite** 8.0.4
- **TailwindCSS** 4.2.2
- **React Router DOM** 7.14.0
- **Lucide React** 1.31.0
- **Lenis** 1.3.25

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
cd ieee-app
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

### Testing

Run tests:

```bash
npm test
```

### Linting

Check code quality:

```bash
npm run lint
```
