# SEO Production Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship production-grade SEO for the IEEE HITU Student Branch Next.js App Router site (JS, not TS) without breaking client interactivity.

**Architecture:** Keep `src/app/**/page.js` as Server Components exporting `metadata`/`generateMetadata`; move all interactivity into existing `src/features/*` client components. Add a central `src/lib/seo.js` site config + `src/components/seo/JsonLd.jsx` + `src/lib/structuredData.js` helpers. Dynamic routes fetch via server `src/lib/server/seoData.js` (direct `src/lib/server/db.js` + static fallback) wrapped in React `cache()`.

**Tech Stack:** Next.js 16 App Router (JS), React 19, `next/font`, `next/image`, `MetadataRoute.Sitemap/Robots`, `application/ld+json`.

**Spec:** This plan implements the user SEO brief (6 tasks: root metadata, dynamic `generateMetadata`, client-component refactor, sitemap/robots, JSON-LD, Web Vitals/semantic HTML). Original brief assumed TypeScript — adapted to JS + JSDoc (see Constraints).

## Global Constraints

- Stack is JavaScript (`jsconfig.json` paths `@/*`), NOT TypeScript — do NOT convert to `.tsx`; use JSDoc typedefs, no `any` equivalent (no untyped objects).
- Do NOT run full `npm test` per change; run only related vitest file, e.g. `npx vitest run src/features/home/components/OfficersSection.test.jsx`.
- Public routes: `/`, `/about`, `/join-us`, `/committees`, `/committees/[slug]`, `/events`, `/events/[slug]`, `/gallery`, `/contact` (+ `/about/founders`, `/membership` if present).
- Private: `/api/*`, `/admin/*`, `/dashboard/*` (if exists) must be `noindex` + disallowed in robots.
- Branding: "IEEE HITU Student Branch", Heliopolis International Technological University (note: Hero copy currently says "Helwan" — flag, do not silently rename).
- Keep recruitment CTAs discoverable, forms labeled/keyboard-usable, placeholder flows not implied as production backend.
- `metadataBase` from `NEXT_PUBLIC_SITE_URL` with fallback `https://ieee-hitu.example.com` (to be replaced with real prod domain at review).

## Review Focus

- Wrong production domain ships in canonical/OG/sitemap and causes duplicate-content penalties — expect all absolute URLs to share one `metadataBase` origin.
- Event/committee slug missing in DB AND static fallback renders generic "Not Found" metadata + `notFound()` instead of crashing or indexing an empty page.
- Client fetch (`useParams`+`/api/*`) leaks into `generateMetadata` or server files import client hooks/`'use client'` and breaks the build.
- Google Fonts `<link>` remains and still render-blocks / shifts layout — expect `next/font` with `display: 'swap'`.
- Raw `<img>` above the fold without `priority`/`sizes`/`alt` hurts LCP — expect `next/image` on hero/cover with descriptive alt.
- Multiple `h1` or skipped heading levels on any view — expect single `h1` per route, sequential `h2`/`h3`.
